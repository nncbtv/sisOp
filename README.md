# Appunti Sistemi Operativi

Questa repository raccoglie il codice/materiale prodotto durante il corso di **Sistemi Operativi**, con particolare focus sullo **svolgimento delle tracce** cercando di spiegare nel modo più semplice possibile ogni riga di codice scritta.

## A chi è utile?

Questo materiale è pensato per gli studenti che dovranno affrontare l'esame di Sistemi Operativi e vogliono un punto di partenza concreto per **capire come svolgere il compito** e ripassare alcuni concetti tramite gli appunti.

## Struttura della Repository
### `CodiciEsercitazioni/`
Contiene il codice con lo svolgimento di tutti gli esercizi visti insieme al prof più quelli lasciati per esercitarsi
### `EsempiEsercizio1/`
Contiene alcuni esercizi svolti in merito al primo quesito del compito
### `RiassuntiTeorici/`
Contiene alcuni argomenti riassunti tramite appunti presi a mano
### `Tracce/`
Contiene una traccia e il relativo svolgimento, codici ed esercizi

---
*La repository potrebbe presentare errori in qualunque delle sue parti, non è da ritenersi essenziale per il superamento dell'esame, essa stessa non fa decadere: studio individuale, approfondimenti, esercitazioni e lezioni.*
